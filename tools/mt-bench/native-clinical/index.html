    Selected native clinical driver¶

    Living document, last changed 2026-11-13 at 2a5f68cf2.

    This is an instrument candidate. plan and dry-run are executable source/model checks. Runtime is blocked before Host construction by the fixed SOURCE_JOIN = 'REQUIRED_BEFORE_RUNTIME' guard. A private JSON flag cannot enable it. The fixture anchors are the completed d003/d831 commissioning pair; they do not become a clinical qualification or a guessed final source freeze.

    The coordinator owns the final recovery/restore/cold/feed/clinical source join, source acceptance, image audit and explicit launch authorization. Preserve both failed episodes and the successful dcfe preparation and resources. This driver uses a NEW nonce/state/output when eventually qualified.

    Source and protocol boundaries¶

    • metadata.cjs first calls the existing exact-source profile admission before loading configuration. It derives eleven constructor slots and the different seven lifecycle participants from actual docs.operations, including the ordinal-one service aliases. It reads source health commands and refuses changed compose inputs. clinical.py regenerates that metadata before accepting a supplied topology; caller JSON never defines new participants or commands.
    • evaluator-fetch.cjs reads the existing private service environment. Only listener metadata is passed to listener resolution; partition parsing receives its private object. It invokes the actual evaluatorInspection client. It never calls load-env, installs admission, creates a PG client or triggers work. Exact CID/birth/source/image and claim bytes are checked around every exec.
    • Ordinary RPC remains available for loader controls. The fixed opt-ins are the reviewed contracts change-feed-v1 and clinical-result-v1. They share existing worker resources and create no additional SQL connection. Raw replies and host command clock brackets remain private. Pure progress/recovery/idle assessors are reused unchanged from m7-joined.
    • All worker starts/stops use the shipped controller and exact ACKs. Raw Compose starts only PG/Vault infrastructure; bootstrap is the source one-shot. There is no raw worker restart, direct psql, admission-file deletion, automatic observer retry or credit refund from census absence.
    • The fixed count CLI receives the complete sixteen-tenant same-marker selector. Closed accepted/uncertain/refused/pending request ledgers and raw status pages are compared with per-tenant SQL aggregates, one unmarked primer seed and all four foreign totals. Both missing rows and misplaced writes inside the roster fail. The two-observer ceiling remains source-controlled and unchanged.

    HTTP, socket and clinical fixture¶

    The host child uses the exact existing stock socket.io-client 4.8.3, source primer HTTP functions and fixed private nonce/sequence IPC. It has a scrubbed HTTP-only environment and imports no Docker, SQL, Vault or worker admission transport. Its target addresses are derived from exact owned CID/image/birth and backend network custody, then rechecked by the orchestrator. API2 is a direct owned target, not a load-balancer inference. The child keeps tenant Host and stock Socket.IO authorization semantics. No production image is changed to install a dev dependency.

    The whole existing host dependency tree, actual Node and Git binaries, helper bytes and versions are hash-pinned; no install is performed. Source preparation uses Git; the HTTP child receives only the Node directory in PATH. Dependency identity is rechecked after the client exits. Raw statuses retain 201; an explicit adapter passes it as accepted to the unchanged source request accountant, whose accepted representation is 200. HTTP receipts retain sequence, tenant, collection, attempt, document date and synthetic body hash in bounded pages. Outcome ledgers are persisted before HTTP begins. Interrupted/pending/5xx outcomes cannot be silently counted as zero writes.

    The primer's one SGV per tenant remains a seed. The clinical fixture adds 288 individually accounted, primary-run-marker SGVs per tenant at five-minute spacing through the source property-loader's one-day horizon, then 64 marked shape writes (entries, devicestatus, Note treatments and probe entries). It exercises source-enabled BG-now/delta history without dosing data. Actual clinical API properties and stock frames are positive witnesses. Cached evaluator metadata must separately match ordinary generation/revision/checkpoint and completion observations. meanPresent/meanFinite mean cached BG-now observation only; they grant no current operation or tenant authority and do not mean every clinical output is available. Identical-content TIME may retain the original model time.

    The shipping evaluation confirmation/creation-age guard remains 60 seconds. Alerts, invalid due/job identity, unavailable BG-now and hidden failed completions fail; readiness and global completion counts alone do not pass. Confirmation age is not request latency. Request-to-frame timing stays within the producer's local monotonic clock and joins the actual synthetic date to a subsequent stock frame.

    Intended fixed episode¶

    1. Bootstrap, bind and start all eleven admitted slots. Source health commands are used for their actual roles. Feed-reader has no invented health endpoint: exact process liveness and later consumer heartbeat/hint/check delivery are separate evidence.
    2. Source-HTTP provision/prime all sixteen tenants; write clinical history and capture successful owned acquisition/output metadata.
    3. Stop the exact seven participants with ACK retirement. Start fresh API2, bind its inspected address, begin first-touch HTTP/stock-socket storm, then start the other six. Retain actual warming/refusal/success outcomes, new CIDs and evaluator runtime IDs. A missed cold request window is not relabelled.
    4. Observe fresh acquisition and strict successful TIME on the full witness set; idle TIME_NOT_EXERCISED never satisfies it. Record due/jobs and cached observation separately from current authority.
    5. Choose A/B using actual different evaluator owners. Keep API2, B's evaluator runtime/generation, realtime process/incarnation and established stock socket unchanged. Stop/ACK only API, collect repeated B DATA write/read/frame and TIME progression while it is stopped, then start API. The causal stop/IPC/reply/start order is evidence; before/after-only observations cannot pass.
    6. Check explicit cross-credential DATA and root-socket refusal with an authorized positive frame. Close HTTP admissions, join raw receipts to request ledgers, then invoke the charged independent count oracle for the complete roster.
    7. Cleanly retire API2's exercised incarnation and check its cold ACK. Start one new API2 incarnation, deliberately kill that exact CID once, and require a typed generation-exhaustion refusal with unchanged credit ledger/process. This declared negative event consumes its credit and never claims a clean ACK.
    8. Stop/ACK the remaining workers, capture retained credits and stop exact owned infrastructure. Failed producer groups are terminated/drained before worker cleanup. Emergency stops grant no retirement.

    Cold evidence consumes the reviewed additive cold.observed v1 ACK schema: peakActive includes delaying+running; peakQueued samples stable post-pump waiting. Final zeros without these peaks are NO-INSTRUMENT. Completed work requires a positive active peak, and the selected storm must actually exercise API2 queueing; a missed queue window refuses rather than passing an unexercised criterion. ACKs must match incarnation, nonce, plan, tags and source before their statistics are considered.

    Finite resource accounting¶

    The proposed global host ceiling is 1,800 seconds, 2,048 commands and 128 MiB raw command output, with 180 seconds, 256 commands and 32 MiB reserved for cleanup. At most eight tagged captures retain another 128 MiB internally; their bounded parent output is charged to the host ceiling. At most 96 evaluator execs/48 rounds retain at most 48 MiB, also charged to host output. Exact snapshot counts remain point measurements, not a peak connection proof.

    The single producer has at most 1,200 seconds, further capped by the remaining host deadline, and 4 MiB stdout/stderr reserved before construction. It admits at most 8,192 explicit HTTP requests and 16 concurrent sockets. The HTTP-wide observer, including source primer and stock handshakes, permits at most 16,384 requests/256 MiB response bytes. Private accounting writes have a separate 256 MiB cumulative bound. Stock Engine.IO packets have an independent 256 MiB cumulative input ceiling and one MiB packet/payload ceiling; source-day frames allow at most 512 SGVs. A late packet-limit breach is persisted and refuses both client close and final accounting; it cannot become a successful closed ledger. A finished producer thread is insufficient cleanup proof: its terminal result must positively confirm the owned group drained, otherwise cleanup retains uncertainty. Receipt pages contain at most 64 records; no page may exceed 64 KiB. Source primer's existing finite warming policy is preserved. These are instrument bounds; none is a product SLO or a production profile.

    Source/model commands¶

    All outputs are NEW private directories; source/runtime preparation is an explicit input. These commands do not start a stack:

    NODE_PATH=/tmp/ns-m7-owned-dependencies-20261112/node_modules \
  node tools/mt-bench/native-clinical/metadata.cjs \
  PRIVATE_PREPARED_ROOT/source-input.private.json NEW_TOPOLOGY.private.json
python3 -B tools/mt-bench/native-clinical/clinical.py plan \
  PRIVATE_PREPARED_ROOT NEW_MODEL_DIR --topology NEW_TOPOLOGY.private.json
python3 -B tools/mt-bench/native-clinical/clinical.py dry-run \
  NEW_MODEL_DIR/clinical-plan.private.json NEW_RECORDING_DIR
python3 -B tools/mt-bench/native-clinical/test_gates.py
node tools/mt-bench/native-clinical/test_client.cjs
node tools/mt-bench/native-clinical/test_stock_client.cjs
python3 -B tools/mt-bench/native-clinical/test_runtime.py

    control_metadata.cjs PRIVATE_PREPARED_ROOT NEW_OUTPUT uses actual source private reader/install guards and partition parsing with a recording RPC port. New helper passes without a claim write; old load-env helper refuses reused claim; restoration passes. It constructs no PG client and makes no network/Docker call.

    Remaining launch gates are the final coherent source/operator qualification, exact deployment/profile/collector/image join and audit, independent driver/model review, new nonce/IPAM/ports/custody plan review, then a bounded authorized actual episode. Current model outputs always retain native acceptance UNMEASURED.

    Independent emergency cleanup uses python3 tools/mt-bench/native-clinical/cleanup.py ORIGINAL_ROOT_CLEANUP_SPEC NEW_PRIVATE_OUTPUT. It validates the original source/image/project/base and full eleven-slot roster, stops only exact inspected identities, preserves uncertainty, and never grants credit retirement. The original result remains unchanged.
