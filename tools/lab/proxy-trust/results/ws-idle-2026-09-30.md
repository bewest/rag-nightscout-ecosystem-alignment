# Proxy-trust lab, idle sockets vs hop timeouts (W3)

Date: 2026-09-30  |  tree: `7000eb18`  |  topology: AR-PP2  |  TRUST_PROXY=2

Every HTTP hop gets `proxy_read_timeout`/`proxy_send_timeout` = the hop timeout (`default` = nginx's 60s). The socket is left idle (no application traffic) for the window; socket.io's own ping is the only traffic. Disconnects are counted with client reconnection on.

| hop timeout | requested transport | ended on | idle window | disconnects | reasons | connected at end |
|---|---|---|---|---|---|---|
| 10 | `websocket` | websocket | 90s | 8 | transport close | True |
| 10 | `polling` | polling | 90s | 8 | transport error | True |
| 20 | `websocket` | websocket | 90s | 4 | transport close | True |
| 20 | `polling` | polling | 90s | 4 | transport error | True |
| 24 | `websocket` | websocket | 90s | 3 | transport close | True |
| 24 | `polling` | polling | 90s | 3 | transport error | True |
| 26 | `websocket` | websocket | 90s | 0 | - | True |
| 26 | `polling` | polling | 90s | 0 | - | True |
| 30 | `websocket` | websocket | 90s | 0 | - | True |
| 30 | `polling` | polling | 90s | 0 | - | True |
| default | `websocket` | websocket | 90s | 0 | - | True |
