License: AGPL-3.0

Heart Rate collection API for Nightscout, enabling storage of biometric data from AID systems and wearable devices.

Based on PR#8083 implementation and AAPS HeartRate entity.

List heart rate readings

Returns heart rate readings within the specified date range. Supports pagination and filtering.

api_secretjwt
query Parameters

string <date-time>

Filter readings on or after this date

date$lte
string <date-time>

Filter readings on or before this date

limit
integer <= 1000
Default: 100

Maximum number of results

skip
integer
Default: 0

Number of results to skip (pagination)

sort
string
Default: "-timestamp"

Sort order. Prefix with - for descending. Example: -timestamp (newest first)

fields
string

Comma-separated list of fields to return

HeartRate

_id
string

MongoDB ObjectId

identifier
string <uuid>

Stable identifier for sync operations. Used for deduplication across systems.

beatsPerMinute
required
number <double> [ 20 .. 300 ]

Heart rate value in beats per minute (BPM)

timestamp
required
integer <int64>

End of sampling period in milliseconds since epoch (UTC). AAPS uses this as the primary timestamp field.

date
string <date-time>

ISO8601 timestamp (alternative to epoch milliseconds)

duration
integer <int64>
Default: 60000

Duration of sampling period in milliseconds. AAPS typically samples over 60-second windows.

device
string

Source device identifier (e.g., smartwatch name/model). Used for attribution and filtering.

utcOffset
integer <int64>
Default: 0

UTC offset in milliseconds for local time calculation

isValid
boolean
Default: true

Data validity flag (false if unreliable reading)

created_at
string <date-time>

Server-side creation timestamp

srvCreated
integer <int64>

Server creation timestamp (epoch ms)

srvModified
integer <int64>

Server modification timestamp (epoch ms)

subject
string

Subject identifier for multi-user installations
