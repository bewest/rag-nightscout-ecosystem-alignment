1. **S11 (wrong numbers).** Does any 15.0.9 change alter the `cob` (or `iob`) object that `/api/v2/properties` returns (the "COB now shows the value reported by your looping app" item)? Nightguard shows `cob.display` directly, so it would show a different COB on the same data. Cross-check the release-note wording against the actual properties output.

Nightguard's v3 path and its v1 fallback depend on both. Read-derived: both look unchanged.
3. **S13 (cosmetic, statistics).** The candidate's v3 sort tie-break and fields-projector rewrite: check that `fields=identifier,_id,date,dateString,mills,type,sgv,mbg,direction,units` (top-level names only) still returns the same keys.
4. **S3 (none expected).** The v1 `find[date][$gt]` value has a fractional-millisecond part; `parseInt` became `parseFloat`. Expected to give the same result on whole-ms stored dates; worth one test row.
