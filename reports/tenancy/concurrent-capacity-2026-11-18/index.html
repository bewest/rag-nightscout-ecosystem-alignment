    Simplification and controls¶

    Reproduced:

    • Mandatory fixed-target catch-up selects itself for supported outcome-gated discovery. Kubernetes uses its existing 120-second drain default when omitted; an authored longer observation budget never extends the per-write clinical deadline. Missing-selection ablations go red and restoration passes.
    • Factory receipts come from the selected image, bind actual evaluator/realtime configuration and provisioning, and require exact row contract digests. The merge retains the historical native codec check for old captures. Both current and older shipping factory controls pass; missing selection, foreign source and wrong row contracts refuse.
    • Host driver serialization is scoped to the canonical fixture path. Same-fixture overlap refuses, independent fixtures can overlap, and removing the lock makes the same-fixture control red. Batch custody, finite clocks, declared allocations, actual resource checks and owned cleanup remain. Shared-host figures are contended.
    • A producer script's recorded source bytes no longer refuse a frozen Compose operation. Actual command, image, role environment, ownership, project and configuration custody remain. Other source/configuration seals mixed with credential or resource custody remain until their property checks are separated.
    • The optional batch resource projection accepts the structured allocation already supported by prepare; invalid numeric allocations still refuse.
    • An explicit clinical stall is classified as FAIL whether the worker is busy or idle. The independent REST discovery path may collect alongside that failure; it cannot grant clinical PASS or capacity acceptance. The actual local-1000 shape has a red/restored control, with unknown codes, alerts, malformed job flags, foreign state, restore and source-binding controls retained.

    No performance arm is required to remove obsolete fixed tenant-count ceilings. The per-tenant advisory-lock bound remains because it protects datastore health. W/versioned output and changes to xdripjs remain deferred. Paid perf-cloud source seals were assessed but not changed in this local/Kubernetes join; no paid run or provider resource was started.
