    Private listener composition and per-operation rules — 2026-11-10¶

    Living document, last changed 2026-11-10 at 8f72be96c.

    MT-ENDPOINT-TRANSPORT (remaining scope), application lane codex/listener-composition-20261110. Composition, per-operation bounds and per-module lifetime are fixed on a local branch with reproduced focused evidence. A separated-process run over a Docker Compose network was executed with the production transport and lifecycle handlers. Real API/realtime/evaluator role processes were not run over Compose (see what blocked it). Nothing was pushed.

    What changed (read-derived from the diff)¶

    • transport.compose(endpoint, modules): one private listener for an explicit list of {service, create, lifetime?} modules. Routes are a fixed table keyed by (method, path). A duplicate route (within or across services) refuses with INTERNAL_API_ROUTE_DUPLICATE, a duplicate service with INTERNAL_API_SERVICE_DUPLICATE, before any endpoint is published. Dispatch requires the service/version headers to name the route's owner; a co-resident or unregistered service is refused (503 SOCKET_IPC_UNAVAILABLE), no handler runs. Each module gets its own transport token.
    • Lifetime is per module. Application modules carry {operationWindow, resolveTenant}; the lifecycle module carries none. No listener-wide window is offered.
    • Operations may declare method (POST only), contentType (application/json only), maxBytes, timeoutMs. Per-operation bounds only tighten the endpoint bounds and apply at listener and client. Both ends check the operation media type (request accepts ; charset=utf-8); the client no longer accepts any media type merely prefixed application/json.
    • transport.open is the one-module form; role wiring is unchanged (one listener per contract). operation-cohort exports controlOperations(cohort), the unchanged lifecycle handlers, so a composed listener can reuse them.

    Compatibility. No internal path, header or schema changed; checked-in contracts declare none of the optional fields. Peers on dc795bd1 and on this lane interoperate on the wire. One client-side tightening: a response whose media type is application/json-prefixed but different (for example application/json-seq) is now refused; current listeners send exactly application/json. No migration note is required for deployments.

    Finding (reproduced, current behaviour): on SIGTERM the transport's close() destroys in-flight connections at shutdown start. The held caller received SOCKET_IPC_UNAVAILABLE after 176 ms, before its handler finished; the server still drained the handler and window. The outcome is reported to the caller as uncertain with no retry, consistent with the documented no-retry contract. A graceful "deliver held responses before closing" mode does not exist; whether one is wanted is a design question for the replica/drain owner, not changed here.

    What stays UNMEASURED¶

    • Real role processes over Compose. nightscout multitenant api|realtime|evaluator with PostgreSQL, Vault, socket forwarding, realtime alarm/checkpoint stores and evaluator consumers were not run on a Compose network. Blocker: no in-tree provisioning composes all three roles; the joined native phases in tests/fixtures/realtime-preview/README.md depend on root-supplied provisioning and configs, and the operation window has no in-tree native PostgreSQL provisioning (only protocol fixtures). Current authority, response drain and tenant-local invalidation over the network are therefore measured with the production transport and lifecycle handlers but synthetic authority, phase and role contexts.
    • PostgreSQL advisory-lock suspension across processes; Vault; clinical data paths.
    • Production role wiring onto a shared component listener (needs a config shape naming the shared endpoint and a boot order registering every module before binding — a decision boundary, not implemented).
    • Direct HTTPS, a bearer protocol, GET metrics/readiness routes (out of scope; follow-ups for the operational module), Kubernetes manifests, fixed-roster replicas.
    • Full database tiers, browser, enabled corpus and CodeQL for this commit: run on the coherent joined candidate, not on this leaf.
