    What the composition is¶

    • roles.js admin: multitenant: true, start → admin-preview.js. Plane, prefix, default host/port, listener: true, storage: 'write' unchanged.
    • The admin listener (ADMIN_HOSTNAME/ADMIN_PORT, existing plane rule) serves exactly the ownership-operations v1 routes through transport.handler (the shared internal transport's route table, header/schema/bound checks), one owned token per module. No credential of its own (D7, decision internal-service-contracts: HTTP access policy belongs to the deployment).
    • MULTITENANT_ADMIN_CONFIG (admin-config.js): version, maxBytes, timeoutMs, ownership: {connectionEnv, namespace, operator: {principal, consumer}, tenants}; nothing else accepted. Operator authority is the shipped tenantSetAuthority over the listed tenants.
    • Startup: shared application connection refuses SUPERUSER/BYPASSRLS (lib/storage/postgres-connection.js:72); the admin readiness check refuses SUPERUSER/BYPASSRLS/CREATEROLE/CREATEDB/REPLICATION; the ownership store's exact privilege screen refuses any other table-privilege shape.
    • serve refuses admin without its configuration, and together with MULTITENANT_OPERATION_CONFIG (admin is not a lifecycle cohort participant).
    • UDS for the admin listener is not offered: the ADMIN listener is HTTP. service.open (UDS or internal HTTP on its own endpoint) is unchanged for other composers.

    Findings¶

    • read-derived: by default nightscout multitenant admin exits 78: the admin default host 127.0.0.1 equals the CLI's consumer fallback HOSTNAME, which the plane rule computes even when api is not served (listeners.js resolve). An operator must set ADMIN_HOSTNAME (another loopback such as 127.0.0.2, or an acknowledged internal address) or HOSTNAME. The unit test pins this behaviour; whether the default should change is a coordinator question.
    • read-derived: the restore cohort census (operation-cohort.js assertComplete) refuses RESTORE_COHORT_UNKNOWN_BACKEND for any connected backend with privileges on a protected namespace that is not a participant's. The admin role's ownership backends are such backends while connected (pool idle connections included). Restore with the admin role running is expected to refuse; the admin role does not join the cohort (serve refuses the combination). Whether ownership changes must be held during lifecycle operations is a decision input.
    • read-derived: the ownership_operator identity holds no control-namespace grant and the admin role composes no operation window, so the lifecycle operation window does not fence ownership changes for a tenant under export/restore/deletion.
