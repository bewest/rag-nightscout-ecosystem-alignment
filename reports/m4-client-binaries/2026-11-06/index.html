    The connector ran unchanged against an M4-only fixed synthetic Share upstream. Each stack stored exactly 240 mapped readings. Restart resent a newest subset, stored no duplicate, preserved logical values and kept srvModified monotonic by stored identity. One poll was selected; incremental new-reading polling remains UNMEASURED. The upstream holds a fixed 20-hour series; its invariant/range controls are covered by pure tests. The shared journey fake upstream was left unchanged after source review reproduced changing historical values from its moving integration window.

    For source mode, the preview held three synthetic A entries and an empty single-site sink received exactly those logical rows. Actual exchange returned 200 with the expected fields; actual Bearer read and sink POST returned 200. B remained unchanged. This is a preview source to single-site sink observation, not a fabricated baseline-as-source differential. Without a token, verifyauth answered 401 and a subjects GET answered 405; onboarding was blocked at the observed steps. Subject creation by POST was not demonstrated.

    Refusal and instrumentation controls¶

    The verified-build default and connector captures exercised actual cgmsim/oref0 credential carriers. A's secret or subject token at B refused reads/writes with 401; revocation refused the next read/write with 401 and restoration read 200; unknown aliases returned 404. Every compared domain's stored values on A, B and baseline remained identical across refused operations.

    Absent-credential oref0 reads returned 401. Its missing-secret upload refused locally with exit 1 and no HTTP request. Separate no-carrier POST protocol probes returned 401 on both stacks; these probes are not actual-client upload execution. cgmsim hashes an empty secret, so that is not an absent-carrier check. Oref0's revoked upload returned HTTP 401 and process exit 0 because its curl invocation lacks --fail.
