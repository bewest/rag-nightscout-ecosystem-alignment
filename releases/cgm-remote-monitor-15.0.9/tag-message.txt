Behaviour changes operators will see: insulin-age URGENT level and a
one-shot notification (IAGE_ENABLE_ALERTS, default off); v1 ?count=0
reads answer [], malformed counts and DELETE with count 0 answer 400,
saves and updates ignore count; refused query operators return 400;
subject and role fields outside the allow-list are not stored;
filters return different (correct) rows; _ no longer becomes a
space in query parameters; voice endpoints ignore request locale;
new TRUST_PROXY setting, unset = previous behaviour, with a boot
message; MongoDB 4.4 deprecated; legacy mmconnect and
DEXCOM_BRIDGE_USE_LEGACY to be retired.

Not in this release: BF-69 quick-pick chooser; BF-86/BF-67 threshold
units; BF-76 silenceTime bound; a planned TRUST_PROXY default flip.
