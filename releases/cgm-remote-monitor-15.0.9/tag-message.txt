one-shot notification (IAGE_ENABLE_ALERTS, default off); v1 count=0
reads return the date window or the default, with a deprecation
warning; malformed counts and DELETE with count 0 answer 400; saves
and updates ignore count; refused query operators return 400; subject
and role fields outside the allow-list are not stored; filters return
different (correct) rows; _ no longer becomes a space in query
parameters; voice endpoints ignore request locale; new TRUST_PROXY
setting, unset = previous behaviour, with a boot message; Loop remote
commands record the sender's address as TRUST_PROXY resolves it, stored
with each remote override; on mmol sites each BG_ threshold is
read on its own, so a site mixing mmol/L and mg/dL thresholds can
store different values (check thresholds after upgrading);
PUMP_WARN_ON_SUSPEND now raises a warning; clock views turn stale
when their fetch fails; an entries POST matching a stored reading
answers with the stored _id; /api/v2/properties cob.treatmentCOB is
a number present only beside a current uploader COB; careportal and
caregiver treatments reach AndroidAPS through API v3 history (applied
per its accept carbs/insulin settings); records AndroidAPS deletes
stop counting; v1 records carry srvModified and srvCreated; IFTTT
applets renamed to translated names must be renamed back; AAPS
percentage switches show scaled values; late or edited AndroidAPS
treatments count in Nightscout's own IOB and COB, and a COB total
that was too high can drop; a v1 list of dates under the date field
works, so xDrip4iOS bulk deletes remove readings; error replies
