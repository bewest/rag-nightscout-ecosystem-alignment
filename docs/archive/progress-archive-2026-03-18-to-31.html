    UVA/Padova 18-ODE Engine Integration (2025-03-30)¶

    Integrated the UVA/Padova physiological simulation model into in-silico-bridge.js as an alternative to the CGMSIM algebraic engine. This addresses GAP-SIM-016 (narrow BG range) and GAP-SIM-001/002 (no sensor noise). The engine uses the low-level Patient API with RK1/2 ODE solver at 1-minute resolution and optional Facchinetti2014 or Vettoretti2019 sensor noise models.
