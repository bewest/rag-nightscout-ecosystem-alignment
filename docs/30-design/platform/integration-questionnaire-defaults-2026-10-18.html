    Integration questionnaire: default answers for Loop, Trio, AndroidAPS and OpenAPS, read from their source¶

    Record

    Record as of 2026-10-18. A point-in-time document; it is not kept up to date.

    Contributor-facing. Snapshot — describes 2026-10-18. Status: current; every answer is a default for the project named in its column to correct. Repository facts are read at this repository's 57a6db95; controller facts at the commits in §1, each checked against the project's current branch head through the GitHub API on 2026-10-18. Every cell is marked R (read-derived: from source; a hypothesis about behaviour), M (measured: the 11-site corpus) or H (history: a release, tag or branch fact from the GitHub API). Current decisions: execution plan §1.

    The question. docs/proposals/integration-questionnaire.md is part of the earlier draft in cgm-remote-monitor's docs/proposals (with agent-control-plane-rfc.md, bridge-rules.md and conflict-resolution.md), which this repository's specifications are proposed to supersede. It asks AID controller projects 16 questions (A1–G16) in 14 tables; each response section reads Pending. Read at cgm-remote-monitor a8888f0d; the file is unchanged on dev fade2299 since db32bdc6 (2026-01-19). The maintainer decided on 2026-10-18 that every answer is filled, for every controller, with a default read from that controller's source and history, and from the corpus where it applies. This page is that fill.

    How to use this¶

    • Each cell is a default for the project to correct. It states what the cited source does at the cited commit. A project corrects a cell by saying what is different; the corrected cell then cites the project and the date.
    • To send a correction: open an issue or pull request on this repository naming the question id and column (for example "C7, Trio"), or answer on cgm-remote-monitor with the label agentic-control-plane as the questionnaire asks. A source link or a test is the fastest correction; a sentence is enough.
    • Where source cannot settle a question (G15 timeline, G16 concerns), the cell gives the default the evidence supports and names what only the project can correct.
    • Columns. The questionnaire's tables carry an OpenAPS column only in A1 and A3; its response list names OpenAPS. Every table here has an OpenAPS column, read from oref0 (the rig).
    • Corpus coverage. The corpus is 11 Nightscout sites (snapshots 2026-04-01 and 2026-04-26), 9 of them Loop. One site carries openaps.* devicestatus, and its openaps.recommendedBolus, pump.bolusIncrement and Exercise treatments are Trio's (M: census paths below; landscape §3.2). The AndroidAPS column is read from source only: the corpus has no AndroidAPS closed-loop site (M: no pump.extended or openaps.enacted.requested path in the devicestatus census). The OpenAPS column is read from source only: the corpus has no oref0 rig (M: no mmtune or preferences path). Census counts are reads across both snapshots, which overlap, so they bound distinct documents from above.
