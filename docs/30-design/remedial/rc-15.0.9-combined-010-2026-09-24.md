## Method

This is the same method as the -59 run.

- Each suite got a fresh `mongo:<ver>` container started with `--ulimit nofile=64000:64000`, which was removed afterwards.
- At each checkout, `npm install --ignore-scripts` and `npm run bundle` ran on Node 20.20.0, then `npm test` ran through `n exec <node>`.
- A suite that printed no mocha totals would have counted as a failure. Every suite printed its totals and exited 0.
