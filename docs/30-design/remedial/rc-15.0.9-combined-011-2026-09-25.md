## Method

- Worktrees at `ab7b22d6` and `4f705217`, `npm ci` on Node 22.23.2 (which also runs the webpack bundle). Each candidate cell ran in its own worktree at `ab7b22d6`, with `node_modules` hard-linked from that install.
- The suite command is CI's (`.github/workflows/main.yml`): `npm run-script test-ci` (mocha under nyc, env from `tests/ci.test.env`), then `npm run-script test:core`.
- Each cell got a fresh `mongo:<ver>` container (`--ulimit nofile=64000:64000`), with no replica set, as in CI. The test runner ran in a second container sharing that mongod's network namespace. That keeps the suite's fixed addresses private to the cell: `127.0.0.1:27017` in `tests/ci.test.env`, and port 1337 in `tests/security.test.js`. It also means the host's own mongod on 27017 is unreachable. Node came from the `n`-managed binaries (`/home/bewest/n/n/versions/node/<ver>`).
- Each cell's server version was read from its mongod before the run (`db.version()`).
- The seven cells ran three, then four, at a time.
- A cell that printed no mocha totals would have counted as a failure. Every cell printed totals and exited 0.
