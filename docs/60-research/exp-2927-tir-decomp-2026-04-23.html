    EXP-2927 — oref1's TIR advantage decomposed: fasted vs post-prandial¶

    Record

    Record as of 2026-04-23. A point-in-time document; it is not kept up to date.

    Date: 2026-04-23 Source: tools/cgmencode/exp_tir_decomp_2927.py Scope: Mechanism attribution for the EXP-2925 oref1 Pareto- dominance. AID-author audience.

    Pooled TIR by (lineage, state)¶

    Lineage State n TIR % TAR % TBR %
    Loop (iOS) FASTED 7 73.93 22.04 4.03
    Loop (iOS) POST_PRANDIAL 7 48.64 49.17 2.19
    oref0 (legacy) FASTED 3 79.77 14.20 6.04
    oref0 (legacy) POST_PRANDIAL 3 70.47 24.85 4.68
    oref1 (modern) FASTED 9 90.52 5.46 4.01
    oref1 (modern) POST_PRANDIAL 9 75.81 21.02 3.18

    Within-tertile Loop → oref1 TIR gap¶

    cf tertile State n_L n_O gap (pp) 95 % CI sig
    low_cf FASTED 1 3 +22.13 (n=1 — degenerate) n/a
    low_cf POST_PRANDIAL 1 3 +48.44 (n=1 — degenerate) n/a
    mid_cf FASTED 3 3 +19.41 [+11.27, +26.46] ★
    mid_cf POST_PRANDIAL 3 3 +27.80 [+7.93, +46.32] ★
    high_cf FASTED 3 3 +11.13 [+1.08, +21.19] ★
    high_cf POST_PRANDIAL 3 3 +18.48 [+0.06, +37.55] ★

    Findings¶

    1. The post-prandial TIR gap exceeds the fasted gap in both significant tertiles.
    2. mid_cf: PP +27.80 vs FASTED +19.41 (PP is ~1.4× larger)

    3. high_cf: PP +18.48 vs FASTED +11.13 (PP is ~1.7× larger) Pooled across cf, PP gap is ~27 pp vs FASTED gap ~17 pp.

    4. Loop's post-prandial TIR is 48.64 % — about half of all post-prandial cells fall out of range. The TAR is 49.17 %. This is the dominant contributor to Loop's overall TIR deficit. EGP handling (FASTED 73.9 %) is comparatively OK.

    5. oref1's PP TIR is 75.81 %. The mechanism stack — UAM detection + dynamic-ISF rising on bolus + SMB-as- correction during absorption — produces a 27-point structural advantage over Loop's brake-only post-prandial response.

    6. Even with autobolus, Loop's PP TIR is much lower than oref1's. From EXP-2921 we know autobolus halves dawn-hyper but morning-hypo persists; this experiment shows autobolus alone does not close the larger PP gap. UAM and dynamic-ISF together likely matter more than autobolus alone for meal handling.

    7. oref0 PP TIR is 70.47 % — only ~5 pp below oref1's 75.81 %. So oref0's UAM + SMB-as-correction subsystem is competitive with oref1 on PP handling. The latency penalty shows up overnight, not after meals.

    Mechanism attribution¶

    Source of oref1 advantage Estimated contribution
    PP carb handling (UAM + SMB + dynamic ISF response) ~60 %
    FASTED EGP handling (dynamic ISF widening) ~40 %

    Both real, both significant. The carb-handling lever has the larger absolute effect; the EGP lever has the cleaner causal isolation (EXP-2922/2923/2924).

    Caveats¶

    • low_cf cells with Loop n=1 cannot inferentially test the gap.
    • time_since_carb_min capped at 360 — patients with truly long fasts all bin into FASTED.
    • Cohort small (n=7 Loop, n=9 oref1). Direction and within- tertile significance both consistent.
    • Mechanism attribution is correlation-based, not interventional. Future natural-experiment / counterfactual would tighten.

    Implication¶

    For AID authors, the design priority order suggested by this cohort is:

    1. Add UAM detection + SMB-as-correction during absorption (largest TIR delta) — the post-prandial 50 % out-of-range rate in Loop is the single largest remediable burden in this data.
    2. Add dynamic-ISF for dawn EGP (cleaner-mechanism delta) — smaller absolute effect but isolated, robust, and addresses a distinct physiologic challenge.
    3. Improve basal-cut latency (oref0's residual gap) — the smallest absolute effect but lowest-effort fix for legacy oref0/openaps codebases.
