    Fix: - Fetch device timezone from profile API - Display device time with "(Device)" label - Show both times when browser/device offsets differ - Shared timeformat utility module

    Gap Impact: - GAP-TZ-001: ✅ Directly addressed (cross-timezone caregiver confusion) - GAP-TZ-007: ⚠️ Partially addressed (still falls back to browser time if no profile)

    Recommendation: Safe to merge - significantly improves UX for caregivers

    The oref0 repository has no active development. TypeScript migration PR (#1472) has been open since August 2024. This confirms: - Algorithm reference is stable but unmaintained - AAPS/Trio have diverged with their own implementations - Conformance testing should use AAPS Kotlin as the "living" reference
